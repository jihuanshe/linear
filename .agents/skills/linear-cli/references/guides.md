# guides

> Version-matched workflow guides

## Usage

```
Usage:   linear guides

Description:

  Version-matched workflow guides

Options:

  -h, --help           - Show this help.
  --workspace  <slug>  - Target workspace (uses credentials)

Commands:

  list           - List version-matched workflow guides
  read   <name>  - Print one guide's Markdown body to stdout
  usage          - Show usage for linear guides
```

## Subcommands

### list

> List version-matched workflow guides

```
Usage:   linear guides list

Description:

  List version-matched workflow guides

Options:

  -h, --help           - Show this help.
  --workspace  <slug>  - Target workspace (uses credentials)
  --json               - Output guide metadata as JSON
```

### read

> Print one guide's Markdown body to stdout

```
Usage:   linear guides read <name>

Description:

  Print one guide's Markdown body to stdout

Options:

  -h, --help           - Show this help.
  --workspace  <slug>  - Target workspace (uses credentials)
```
